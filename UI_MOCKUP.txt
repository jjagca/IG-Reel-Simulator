KEY FEATURES:

✓ CAMERA LAYER (Background)
  • Live camera preview from back camera
  • Full-screen coverage with aspect fill
  • HD quality (1920x1080)
  
✓ OVERLAY LAYER (Foreground)
  • Semi-transparent UI elements
  • Vector graphics (SF Symbols)
  • White text with shadows for visibility

✓ RIGHT SIDE ACTIONS
  ❤️  Like Button (245K likes shown)
  💬  Comment Button (1,432 comments)
  ✈️  Share Button
  ⋯   More Options
  🎵  Audio Thumbnail (rotating animation)

✓ BOTTOM LEFT INFO
  👤  Profile Picture (gradient ring)
  •   Username display
  •   Follow button (outlined)
  •   Caption preview (2 lines)
  •   Audio track information

✓ TOP BAR
  ←   Back navigation
  📷  Camera/switch button

COLOR PALETTE:

PRIMARY:
• UI Elements: White (#FFFFFF)
• Text: White with shadow
• Background: Live camera (full color)

ACCENTS:
• Gradient 1: Purple → Pink → Orange (profile ring)
• Gradient 2: Purple → Pink (audio thumbnail)
• Semi-transparent: Black @ 20% opacity (button backgrounds)

SHADOWS:
• All text: Black shadow for readability
• All icons: Subtle drop shadow for depth

Language:      Swift 5.0
